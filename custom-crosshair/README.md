# Custom Crosshair (Fabric, Minecraft 26.2)

Клиентский мод: рисуешь свой прицел сам и настраиваешь его как хочешь.

## Возможности

- **Пиксельный редактор** (по умолчанию клавиша `K`): ЛКМ рисует, ПКМ стирает, СКМ — пипетка.
- Сетка от 3x3 до 31x31, зеркальное рисование (↔, ↕, в обе стороны).
- **Цвет**: ползунки R/G/B/прозрачность + палитра; «Перекрасить» красит весь прицел в текущий цвет.
- Шаблоны: крест, крест с зазором, точка, круг, X, T, квадрат.
- **Размер** (0.25x–8x), **поворот** (0–355°), **отражение** по горизонтали/вертикали, **сдвиг** по X/Y, непрозрачность, обводка (чёрная/белая).
- **F3 и F5**: прицел остаётся на том же месте. В F5 (вид от 3-го лица) ванильный прицел пропадает, а этот — нет;
  в F3 вместо ванильных осей рисуется твой прицел. Оба поведения можно выключить в редакторе.
- Индикатор перезарядки удара под прицелом (можно выключить).
- Клавиша «Вкл/выкл свой прицел» (по умолчанию не назначена) — быстро вернуть ванильный прицел.
- Все клавиши меняются в Настройки → Управление → «Свой прицел».

Настройки сохраняются в `config/customcrosshair.json`.

## Установка

Нужны Fabric Loader ≥ 0.18.4 и Fabric API для 26.2. Положи `custom-crosshair-1.0.0+26.2.jar` в папку `mods`.

## Сборка

```
cd custom-crosshair
./gradlew build
```

Нужен JDK 25. Готовый jar будет в `build/libs/`. Его же собирает GitHub Actions (workflow «Build Custom Crosshair mod»,
артефакт `custom-crosshair`).
