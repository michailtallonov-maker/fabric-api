# Tunnel Miner (Fabric, Minecraft 26.2 и 26.3, клиентский)

Ломаешь киркой блок — вместе с ним ломается квадрат 3×3 вокруг него, получается прямой туннель 3×3.

- Только клиент: ставится в `mods` у себя, на сервер ничего ставить не нужно.
- **Одиночный мир:** все 9 блоков ломаются моментально. Каждый блок ломается так, будто ты сломал его сам:
  выпадает дроп и тратится 1 прочность кирки за каждый блок (зачарование «Прочность» работает).
- **Сервер:** моментально сломать блоки клиентский мод не может, сервер такое отклонит.
  Поэтому остальные 8 блоков докапываются по очереди с обычной скоростью кирки.
- Квадрат стоит перпендикулярно взгляду. Если смотреть сильно вниз или вверх, копается пол или потолок 3×3.
- Ломаются только блоки для кирки или лопаты (камень, руда, земля, гравий…). Не ломаются: бедрок,
  жидкости, сундуки, печи, спавнеры и другие блоки с содержимым, а также блоки, с которых эта кирка ничего не добудет.
- Останавливается, если у кирки осталось ≤2 прочности, чтобы она не сломалась.
- Клавиша **B** — включить/выключить (по умолчанию выключен). Меняется в Настройки → Управление → Tunnel Miner.

Для туннеля ростом с игрока ломай блок на уровне глаз: тогда квадрат займёт высоту от пола до блока над головой.

## Установка
Fabric Loader + Fabric API для своей версии, положить jar своей версии (`tunnel-miner-1.0.0+26.2.jar` или `tunnel-miner-1.0.0+26.3.jar`) в `.minecraft/mods`.

> На серверах с античитом автокопание может считаться нарушением правил — используйте на свой риск.
