# Ore Vein Miner (Fabric, Minecraft 26.2, клиентский)

Ломаешь один блок руды киркой — мод сам докапывает всю соединённую жилу.

- Только клиент: ставится в папку `mods` у себя, на сервер ничего ставить не нужно.
- Работает в одиночном мире и на серверах: каждый блок жилы добывается обычным способом
  (с реальным временем копания), поэтому сервер видит обычное ломание блоков.
- Любая кирка; руда должна подходить кирке (каменной киркой алмазы не копаются).
- Руда определяется по id блока (`*_ore`, `ancient_debris`), обычная и глубинная (deepslate) руда
  считаются одной жилой. Работает и с рудами из других модов, если их id заканчивается на `_ore`.
- До 64 блоков за раз, в радиусе 8 блоков от первого; блоки вне досягаемости пропускаются.
- Останавливается, если у кирки осталось ≤2 прочности, если сменить предмет в руке или открыть меню.
- Клавиша **V** — включить/выключить (меняется в Настройки → Управление → Ore Vein Miner).

## Установка
1. Fabric Loader для 26.2 + Fabric API.
2. Положить `ore-vein-miner-1.0.0.jar` в `.minecraft/mods`.

## Сборка
Нужна Java 25: `./gradlew build`, jar появится в `build/libs/`.
Также собирается автоматически в GitHub Actions (workflow «Ore Vein Miner», артефакт `ore-vein-miner`).

> На серверах с античитом автокопание может считаться нарушением правил — используйте на свой риск.
