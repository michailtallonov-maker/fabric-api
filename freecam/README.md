# Freecam

Клиентский мод фрикама для Fabric (Minecraft 26.3). Отделяет камеру от игрока: можно свободно летать и проходить сквозь блоки.
Мод полностью клиентский: на сервер ничего не отправляется, поэтому он работает в одиночной игре и на любом сервере.
Ставить его на сервер не нужно.

## Управление

| Клавиша | Действие |
| --- | --- |
| **F4** (меняется в «Настройки → Управление → Фрикам») | включить или выключить фрикам |
| W / A / S / D | лететь вперёд, влево, назад, вправо (относительно взгляда) |
| Пробел / Shift | вверх / вниз |
| Ctrl (бег) | лететь в 3 раза быстрее |
| Мышь | смотреть по сторонам |

Пока фрикам включён:
- персонаж стоит на месте и не двигается, его видно со стороны;
- ломать, ставить блоки и бить нельзя, чтобы случайно не сделать что-то «из камеры» (сервер бы это всё равно отклонил);
- при смерти, смене измерения или выходе с сервера фрикам выключается сам.

## Сборка

Нужен JDK 25.

```sh
cd freecam
./gradlew build
```

Готовый `.jar` появится в `freecam/build/libs/`. Положи его в папку `mods` вместе с [Fabric API](https://modrinth.com/mod/fabric-api).

Мод также собирается автоматически в GitHub Actions (workflow **Build Freecam**), а готовый jar можно скачать оттуда из артефактов.

Запустить игру с модом из исходников: `./gradlew runClient`.
