# Vent Portal Frame (датапак)

Даёт админу в креативе декоративную «космическую» рамку портала Энда — сразу с вставленным Оком Края.
Рамка чисто визуальная: портал из таких рамок **не открывается**, потому что ванильная игра
активирует портал только в момент, когда игрок сам вставляет Око. Уже заполненные рамки,
поставленные из инвентаря, ничего не делают.

## Установка
1. Скопируй папку `vent_portal_frame` в `<мир>/datapacks/` на сервере.
2. Выполни `/reload` (или перезапусти сервер).
3. Проверь: `/datapack list` — в списке должен быть `file/vent_portal_frame`.

## Использование
- `/function vent:give` — выдать себе 12 рамок (нужен OP и креатив).
- `/execute as <ник> run function vent:give` — выдать другому игроку (он тоже должен быть в креативе).

## Права
`/function` по умолчанию доступна только операторам (уровень прав 2+), так что обычные игроки
команду запустить не смогут. Дополнительно функция отказывает, если игрок не в креативе.
