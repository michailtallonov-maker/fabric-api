# Vent Portal (датапак)

Даёт админу в креативе блок «Портал Энда» (`minecraft:end_portal`) — тот самый космический.
У этого блока в игре нет предмета, поэтому датапак выдаёт предмет-ставилку.

## Установка
1. Положи `vent_portal_frame.zip` (или эту папку) в `<мир>/datapacks/`.
2. Выполни `/reload`.

## Использование
- `/function vent:give` — получить предмет «Портал Энда» (нужен OP и креатив).
- ПКМ по блоку пола — этот блок превращается в невидимый барьер, а под ним появляется портал Энда.
  По нему можно ходить: космос виден под ногами, но портал не телепортирует, потому что до него не дотронуться.
- Shift + ПКМ по такому порталу — убрать (барьер и портал станут воздухом).

Предмет работает только у игроков в креативе. Дальность — 6 блоков.
